# Plaza Sargento Lores visitor guide

Independent Spanish guide for Iquitos, with native server-rendered Open-Meteo weather and existing Google Analytics settings.

Use Node24.12+ and pnpm11. Run `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm build`. Cloudflare Workers builds the server output; the observed project is `plazasargento`.

Public facts and dates appear on the guide. Native SVG images are clearly labeled conceptual illustrations, not documentary photographs or site plans.
